## Этапы миграции

В файле main.tf развернуты не все необходимые компоненты и кол-во выделенных ресурсов было уменьшено.

### Ресурсы и параметры
Виртуальные машины:
- 4 vCPU + 8 GB RAM
- Ubuntu 22.04 - стабильная LTS версия
- 20 GB SSD для локального кеширования и временных данных

Сетевая архитектура
- NAT Gateway - безопасный исходящий интернет-доступ
- сегментация доступа по портам для разных сервисов
- разрешение внутренней коммуникации в подсети
- ограничение внешнего доступа только необходимым портам

Хранилище
- MinIO bucket 10 TB - для хранения основных данных
- Backup bucket 5 TB - для резервный копий
- PostgreSQL 20 GB - для метаданных Datahub и служебных данных

### Причины использования декларативного подхода
- предсказуемость, описывается только конечная конфигурация
- простота, не нужно описывать шаги для получения нужной конфигурации

### Преимущества Infrastructure as Code
- автоматизация задач по обслуживанию инфраструктуры
- снижение вероятности ошибок
- восстановление инфраструктуры за минуты при сбоях
- быстрое развёртывание в новых регионах для географического расширения
- идентичные тестовые среды для качественного тестирования
- легкое добавление новых узлов в data platform через копирование ресурсов
- автоматическое масштабирование групп ВМ
- шаблонизация для быстрого создания окружений
- чёткое понимание стоимости инфраструктуры через код
- оптимизация ресурсов на основе фактического использования
- автоматическое управление жизненным циклом ресурсов
- встроенные security policies через группы безопасности
- документированная инфраструктура для аудитов
